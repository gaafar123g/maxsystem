# MAX SYSTEM — ماكس سيستم للبرمجيات
موقع ثابت (HTML + CSS + JavaScript + Bootstrap 5.3) ثنائي اللغة: العربية (RTL، الافتراضية) في الجذر، والإنجليزية في `en/`.
Static bilingual site — Arabic in the root, English in `/en`. No build step needed to run it.

## 1) التشغيل المحلي / Run locally
افتح `index.html` مباشرة، أو شغّل خادمًا محليًا: `python3 -m http.server 8000` ثم افتح http://localhost:8000
(يحتاج الإنترنت لتحميل Bootstrap والأيقونات والخطوط من CDN.)

## 2) أرقام التواصل والسوشيال / Contacts & social — ملف واحد
عدّل `assets/js/config.js` فقط:
- `contact.whatsapp` / `contact.phone`: رقم للسعودية ورقم لمصر (واتساب بالصيغة الدولية أرقام فقط، مثل `9665XXXXXXXX`). أي رقم فارغ لا يظهر.
- `email`, `address`, `hours`, `social` (روابط كاملة https://…).
- عند وجود رقمين يظهر زر واتساب العائم بقائمة اختيار (السعودية/مصر)، وعند رقم واحد يفتح مباشرة.
- أيقونات الاتصال والواتساب والسوشيال ظاهرة دائمًا. ما لم تُضبط بعد في config.js تقود لصفحة «تواصل معنا»؛ وبمجرد وضع الرقم أو الرابط تعمل مباشرة. (عند ضبط حساب سوشيال واحد على الأقل تظهر الحسابات المضبوطة فقط.)
- النصوص الفارغة (الإيميل، العنوان، ساعات العمل) تبقى مخفية.

## سلايدر الصفحة الرئيسية (بعرض الشاشة كاملة)
ثلاث شرائح بعرض كامل في أعلى الصفحة الرئيسية. الصور في `assets/img/slides/` (web.svg, marketing.svg, data.svg) والنصوص في `_build/extra.py` (`hero2.slides`) والشكل في `style.css` (قسم 17). تتبدل كل 6 ثوانٍ وفيها أسهم وشريط تقدم وسحب باللمس.

## الشريط العلوي والتحميل
الشريط العلوي (اتصال، واتساب، إيميل، سوشيال) يقرأ من `config.js`. شاشة التحميل أيقونة كود بحركة جديدة (قسم 4 في `style.css`).

## 3) نموذج التواصل / Contact form
الموقع ثابت بلا خادم، لذلك:
- ضع في `form.endpoint` رابط خدمة استقبال (Formspree أو Web3Forms أو مثيلهما). لـ Web3Forms ضع المفتاح في `form.accessKey`. تظهر رسالة النجاح فقط عند رد ناجح من الخدمة.
- إن تُرك فارغًا: يعرض النموذج رسالة صريحة أن الإرسال المباشر غير مفعّل ويعرض زر «أرسل الطلب عبر واتساب» برسالة جاهزة (يحتاج رقم واتساب في config.js).
- حماية: حقل Honeypot ومؤقّت زمني، والتحقق من أرقام السعودية (05XXXXXXXX / +9665…) ومصر (01[0125]XXXXXXXX / +201…).

## 4) النطاق (الدومين) / Domain
الروابط الأساسية (canonical, hreflang, sitemap, robots, OG) تحمل `https://www.your-domain.com` كقيمة مؤقتة. غيّرها بإحدى طريقتين:
1. بحث واستبدال في كل الملفات: `https://www.your-domain.com` ← نطاقك.
2. `pip install jinja2` ثم `python3 _build/build.py --site-url https://نطاقك.com` (يعيد توليد 44 صفحة).
> صفحة `404.html` تستخدم روابط تبدأ بـ `/` فتعمل عند النشر على جذر النطاق.

## 5) التحليلات / Analytics
ضع `gtmId` أو `ga4Id` أو `metaPixelId` في config.js. لا تُحمَّل إلا بعد موافقة الزائر عبر شريط الكوكيز (يظهر فقط عند وجود معرّف).

## 6) النشر / Deploy
ارفع محتويات المجلد (بدون `_build` إن شئت) إلى أي استضافة ملفات ثابتة: Netlify, Cloudflare Pages, GitHub Pages, Vercel أو cPanel. للاستضافة الذاتية لـ Bootstrap ضع ملفاته في `assets/vendor` وعدّل الروابط في `_build/build.py` (قاموس CDN) ثم أعد التوليد.

## 7) تعديل المحتوى / Editing content
النصوص موجودة داخل صفحات HTML الناتجة. للتعديل الواسع عدّل `_build/content.json` و`_build/extra.py` و`_build/templates/` ثم أعد التوليد. التصميم في `assets/css/style.css` (الألوان في أول الملف كمتغيرات).

## ملاحظات مهمة / Notes
- المشاريع في الموقع نماذج لأنواع الأعمال (عليها وسم «محتوى توضيحي» وكلمة «نموذج» في العنوان)، فاستبدلها بأعمال حقيقية بعد إذن العملاء. شارة «منذ 2009» مأخوذة من بياناتكم. لا توجد أرقام أو شهادات أو تقييمات مخترعة.
- قسم «السعودية ومصر» يصف ما نراعيه (بوابات الدفع، حماية البيانات، المنصات)؛ **راجع صحة كل نقطة قبل النشر** وعدّلها حسب ما تقدّمونه فعليًا. الصفحتان القانونيتان مسودة تحتاج مراجعة قانونية.
- لا نعد بنتائج ترتيب في محركات البحث، وأتعاب إدارة الإعلانات منفصلة عن ميزانية الإعلانات.
